# Правила проекта MGTS

Все сессии, включая автоматизацию координатора, выполняют команды проекта, сборку, тесты и интеграцию в локальной копии MGTS. Используй PowerShell на Windows и Bash на Linux.

При старте и после каждого переподключения проверь среду:

1. В PowerShell проверь, что `[Environment]::OSVersion.Platform` возвращает `Win32NT`. В Bash проверь, что `uname -s` возвращает `Linux`.
2. Проверь, что текущий каталог совпадает с корнем копии MGTS, открытой в этой сессии. Для сверки используй `git rev-parse --show-toplevel`.
3. Открой и прочитай `COORDINATION.md` из корня проекта.

Если проверка не проходит, останови запуск и сообщи, какая проверка не прошла. Используй ту же локальную копию проекта до конца сессии. Работай в нативной среде без WSL и облачных машин.
