# Правила проекта MGTS

Все сессии, включая автоматизацию координатора, выполняют команды проекта, сборку, тесты и интеграцию только на локальной Windows в PowerShell. Рабочая папка — `C:\Users\Professional\PycharmProjects\MGTS`.

При старте и после каждого переподключения проверь, что `[Environment]::OSVersion.Platform` возвращает `Win32NT`, текущий каталог совпадает с этой папкой и `COORDINATION.md` доступен для чтения. Если проверка не проходит, останови текущий запуск и сообщи, какая проверка не прошла. Переход в WSL, Linux, облачную среду или другую копию проекта запрещён.
