# Проверка альтернативной позы при согласованном ложном треке

Опция localize --recover-drift запускает глобальный поиск после сигнала составного правила №164. Основная гипотеза продолжает вести траекторию. До подтверждения строки получают статус uncertain. Следующий скан с новой меткой не позднее 0,35 с должен независимо принять глобальную позу в пределах 20 см и 6° от предсказанной альтернативы. После отказа новая попытка возможна через 0,5 с. В summary.json поле drift_recovery.history сохраняет времена предупреждений, предложения, подтверждения и причины отказов. Обычный --recover отдельно обслуживает пропуски.

В парном тесте из 12 сканов после третьего такта задан скачок 8,6 м в соседний коридор. Номинальный интервал 0,1 с. Столбцы длительности считают время уверенной ошибки >20 см по числу тактов. Задержка считается от первого такта после вмешательства.

| Сцена | Ошибочный matched, --recover / вместе, с | Восстановление, --recover / вместе | Ложные переключения |
|---|---:|---|---:|
| Правильная траектория | 0 / 0 | сразу / сразу | 0 |
| Соседний коридор с неполной геометрией | 0,9 / 0 | отсутствует / 0,1 с | 0 |
| Полностью симметричные участки | 0,9 / 0,9 | отсутствует / отсутствует | 0 |
| Два одинаковых частичных участка | см. JSON прогона | альтернативы отклонены, все 12 тактов uncertain | 0 |
| Чужая геометрия сканов | 0 / 0 | отказ обоих | 0 |
| Выпадение трёх сканов | 0 / 0 | 0,3 с / 0,3 с | 0 |

При полной симметрии ошибка проходит саму проверку №164 и альтернативный поиск не вызывается. При неоднозначном глобальном поиске после сигнала явная неопределённость сохраняется. На полном синтетическом офисе CLI с обеими опциями сопоставил 100/100 тактов без попыток переключения. Полевой выигрыш не установлен.

~~~powershell
& .\.venv-mgts\Scripts\python.exe -m tools.drift_recovery_trial
& .\.venv-mgts\Scripts\python.exe -m pytest -q tests/test_recovery.py tests/test_quality.py
~~~
