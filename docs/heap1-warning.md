# Предупреждение о большой ошибке XY на HEAP-1

Проверяем, можно ли заметить ненадёжную привязку по доле принятых лидарных точек. Для каждого скана со статусом `matched` предупреждение срабатывает при `inlier_fraction < 0.55`. Эталон CPT7 используется для оценки ошибки XY. Ошибкой считаем отклонение более 0,20 м. Пороги зафиксированы в [протоколе №160](https://github.com/Ivana-banana/MGTS/issues/160) до проверки трёх дополнительных окон.

Короткая карта построена по 40 сканам обхода, длинная — по 300. Для каждого окна обе карты получают одни и те же сканы инспекции и одну и ту же известную первую позу. Поэтому эксперимент проверяет ведение по карте при известном старте. Исходное окно 2560–2619 использовалось при выборе гипотезы. Остальные три окна принадлежат тому же повторному визиту, соседние сканы зависимы.

## Результаты

На трёх дополнительных окнах правило обнаружило 99 из 179 ошибок больше 20 см (55,3%) и дало 3 ложные тревоги на 181 точную привязку (1,7%). В окне 2620 на длинной карте оно пропустило 43 из 60 больших ошибок. Отсутствие предупреждения даёт слишком мало оснований считать позу надёжной. Оставляем правило в экспериментальном оценщике.

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Короткая | 2560 | 4,75 | 0 | 7 | 53 | 0 | — | 11,7% |
| Длинная | 2560 | 32,62 | 59 | 0 | 0 | 1 | 98,3% | — |
| Короткая | 2620 | 4,13 | 0 | 1 | 59 | 0 | — | 1,7% |
| Длинная | 2620 | 28,76 | 17 | 0 | 0 | 43 | 28,3% | — |
| Короткая | 2680 | 2,89 | 0 | 1 | 59 | 0 | — | 1,7% |
| Длинная | 2680 | 26,44 | 36 | 0 | 0 | 24 | 60,0% | — |

Прочерк означает нулевой знаменатель. В каждой строке оценены 60 из 60 сканов, все имели статус `matched`, долю принятых точек и эталон. Базовое правило, доверяющее каждому `matched`, на трёх дополнительных окнах пропустило все 179 больших ошибок и дало 0 ложных тревог. Все большие ошибки пришлись на длинную карту. Три дополнительных окна охватывают почти неподвижную часть одного визита. Эти частоты описывают данный маршрут; для оценки переноса нужен независимый маршрут с движением.

## Воспроизведение

Из корня MGTS в Windows PowerShell используйте карты из [сравнения двух обходов](heap1-map-anchors.md) и 180 дополнительных сканов из [проверки повторного визита](delayed-start.md). При других путях задайте `--initial`, `--heldout`, `--short-map`, `--long-map`. Для повтора выберите новый каталог результата.

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m tools.heap1_warning_inputs --output out/issue160-repeat
& $python -m tools.heap1_warning_score out/issue160-repeat/index.json out/issue160-repeat/scores.json
& $python -m pytest -q tests/test_heap1_warning_score.py tests/test_metrics.py
```

JSON содержит отдельные счётчики для пропусков сканов, статусов вне `matched`, отсутствия геометрической поддержки и эталона. Эталон интерполируется только внутри его временного диапазона, с ограничением разрыва в три медианных интервала CPT7.
