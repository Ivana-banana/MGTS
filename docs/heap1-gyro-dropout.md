# Частичный отказ гироскопа на повороте HEAP-1

На 60 сканах повторной инспекции HEAP-1 локализатор сохранил привязку при отказе гироскопа на 0,5 и 1 с в середине окна. Первый полный межскановый интеграл гироскопа появился через 200 и 150 мс после конца соответствующего отказа.

Данные — миссия ETH Zürich GrandTour от 14 ноября 2024 года. Карта построена по кадрам Velodyne 150–189, инспекция использует кадры 2560–2619. Для четырёх запусков штатного `localize` взята одна поза из результата слепого поиска `delayed` на исправной записи. Кинематическая одометрия отключена. Эксперимент проверяет сопровождение с фиксированной стартовой позой. [Источник и подготовка записей](public-data.md) · [Получение слепого старта](delayed-start.md)

В копии ROS 2 bag только для заданного полуинтервала установлено `angular_velocity_covariance[0] = -1`. Метки сообщений сохранены. Отсчёт времени начинается с первого скана инспекции. CPT7 используется при оценке в общей системе карты, после всех четырёх запусков.

| Пропуск, с от старта | Недоступно сообщений IMU / межскановых интегралов | ATE XY, см | Абсолютный курс, RMSE в градусах | Сопоставлено | До первого доступного интеграла после отказа |
|---|---:|---:|---:|---:|---:|
| Контроль | 0 / 0 | 4,820 | 0,4155 | 60/60 | — |
| 2,700–3,200 с | 200 / 7 | 4,791 | 0,4181 | 60/60 | 0,200 с |
| 2,450–3,450 с | 400 / 11 | 4,775 | 0,4169 | 60/60 | 0,150 с |
| Повтор контроля | 0 / 0 | 4,820 | 0,4155 | 60/60 | — |

Траектории двух контрольных запусков совпали побайтово. Во время обоих отказов каждая метка сохранила статус `matched`, поэтому эпизода восстановления привязки не было. Для интеграла требуется покрытие всего интервала между соседними сканами; его задержка зависит от положения границ отказа относительно сканов. По CPT7 за всю инспекцию курс изменился на 38,05°, а за выбранные пропуски — лишь на 1,82° и 3,25° (интерполяция на границах). Эти результаты относятся к середине данного поворота; для вывода о более быстром вращении нужен отдельный опыт.

Из корня MGTS в PowerShell, с подготовленными данными и новой выходной папкой:

```powershell
python -m tools.heap1_gyro_dropout out/heap1-revisit-v2 out/heap1-full-blind-48 out/gyro-dropout-repeat
```

Файл `report.json` содержит ошибки, число изменённых сообщений, относительные метки всех сканов с недоступным приращением и задержки. Рядом сохраняются копии двух изменённых записей и четыре результата локализации.
