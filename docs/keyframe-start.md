# Влияние локальной регистрации на слепой старт

Регистрация по ключевым сканам дала правильный старт на трёх синтетических окнах, где попарный ICP отказал. Оба метода отказали на четырёх отрицательных контролях. На реальном повторном посещении HEAP-1 оба метода нашли старт, но с ключевыми сканами ошибка положения выросла с 8,51 до 12,41 см. Поэтому вариант с ключевыми сканами доступен как отдельный экспериментальный флаг; по умолчанию поиск использует попарный ICP.

Варианты получают одни и те же первые 51 скан и проверяют глобальные привязки через каждые десять сканов со штатными порогами. Режим `keyframes` один раз строит локальную траекторию от нулевой позы через `slam.track` с пустой собственной сеткой. Кинематическая одометрия отключена; доступное приращение гироскопа используется между кадрами. Предсказание без подтверждения ICP прерывает поиск. Эталон используется только при оценке результата.

На HEAP-1 попарный ICP дал 0,82° ошибки курса и ATE 4,82 см. Оба варианта сопоставили все 60 сканов. На первых трёх информативных синтетических маршрутах снижение локального дрейфа восстановило согласие глобальных привязок; на участке с ограниченной дальностью ошибка смещения превышала 2,5 м при обоих способах. Ложных стартов в этих опытах не наблюдалось.

## Воспроизведение

Семь синтетических окон и обе локальные цепочки проверяются одной командой. Для полевого сравнения подготовьте входы согласно [исходному эксперименту](delayed-start.md). Параметр `--reference` включает ретроспективную оценку.

```powershell
python -m pytest -q -s tests/test_delayed_start_controls.py
$d = 'out/heap1-revisit-v2'
foreach ($method in 'pairwise', 'keyframes') {
    python -m mgts_nav.delayed_start "$d/inspection" "$d/profile.json" out/heap1-revisit-map/map.yaml --local-method $method --reference "$d/inspection-reference.csv"
}
```
