# Новые препятствия в известных проходах

После штатного `localize` можно найти группы лидарных возвратов, повторно наблюдаемые в ранее свободных клетках. Передайте запись инспекции, её траекторию, карту обхода и тот же профиль датчиков. Команда из корня MGTS в Windows PowerShell создаёт новый файл JSON.

```powershell
& .\.venv-mgts\Scripts\python.exe -m mgts_nav.obstacles out/my-first-demo/data/inspection --map out/my-first-demo/map/map.yaml --trajectory out/my-first-demo/inspection/trajectory.csv --config configs/example.json --out out/obstacles.json
```

Отчёт указывает общее число сканов и число сканов со статусом `matched` на точной временной метке. Статусы прогноза и пропущенные метки исключаются. Для каждого события записываются средние координаты наблюдаемой поверхности в метрах системы карты, время первого и последнего наблюдения, время подтверждения и число разных сканов. Время дано в секундах по часам записи.

**Правило подтверждения.** Свободная клетка должна иметь квадратную окрестность из свободных клеток радиусом не менее 0,12 м с округлением вверх до целой клетки. В одном скане нужны хотя бы три разные клетки, соединённые шагами до 0,20 м или 1,5 размера клетки, если это больше. Между сканами ближайшие центры групп сопоставляются с уже наблюдёнными группами в пределах 0,35 м от их среднего центра, один раз за скан. Третье наблюдение подтверждает событие. После перерыва более 0,5 с начинается новое событие.

## Проверка на парных инспекциях

Две синтетические записи ROS 2 содержат по 30 сканов с частотой 10 Гц. Дальномер неподвижен в комнате 10 × 8 м. Исходная карта задаёт стены и свободный пол. Начальная поза передана штатному `localize`; координаты для отчёта взяты из его выходного CSV. Шум дальности и его seed одинаковы. Во второй записи через секунду появляется цилиндр радиусом 0,30 м, перекрывающий лучи к дальней стене.

| Сценарий | Сканы с подтверждённой позой | События |
|---|---:|---|
| Исходная комната | 30/30 | 0 ложных |
| Цилиндр с центром (1,20; 0,80) м | 30/30 | 1 событие, 20 наблюдений, средняя точка поверхности (0,96; 0,75) м |
| Та же запись, у всех 20 сканов с цилиндром статус изменён на prediction_only | 10/30 | 0 |

Первый возврат от цилиндра пришёл в 251,035 с, подтверждение в 251,235 с. Задержка составила 0,20 с от первого скана с препятствием и 0,235 с от его появления. В отдельном контроле пять наблюдений группы в зоне с неизвестной занятостью дали ноль событий. Та же группа в свободной области подтвердилась.

```powershell
& .\.venv-mgts\Scripts\python.exe -m pytest -q -s tests/test_obstacles.py
```

**Границы применимости.** Группа отмечает изменение относительно карты. Причину изменения, тип объекта и его движение этот отчёт не устанавливает. Ошибка привязки со статусом matched или устаревшие сведения о свободном пространстве способны дать ложное событие. У стен, в неизвестных областях, при редких возвратах и длительных разрывах возможны пропуски. Соседние предметы могут попасть в одну группу, а длительное исчезновение или смещение предмета может дать несколько событий. Два коротких прогона с неподвижным датчиком показывают поведение на контролируемой сцене; частота ложных событий на реальной инспекции пока неизвестна.

## Контроль ошибки позы на движущейся инспекции

Статический обход офиса с seed 37 дал карту с клеткой 8 см. На двух независимых инспекциях (seeds 53 и 97) робот движется по одному маршруту, по 100 сканов за 10 с. В парной записи с момента 2 с присутствует цилиндр радиусом 0,30 м с центром (1,25; 2,10) м. Лучи берут ближайшее пересечение со стеной или цилиндром. В контрольной записи есть только стены. Для каждой пары использованы одинаковые выпадения (10%) и шум дальности (σ = 8 мм). В варианте с коротким обзором из тех же измерений оставлены возвраты с дальностью до 2,5 м. [Протокол до прогона](https://github.com/Ivana-banana/MGTS/issues/154#issuecomment-7150191773)

Начальная поза для localize смещена на +0,45 м по X карты. Для каждой записи штатная команда obstacles запущена трижды: с полученной траекторией, с истинными позами и с истинными позами плюс постоянное смещение +0,45 м по X. Во всех трёх траекториях использованы ровно те метки, которым localize присвоил matched. Это позволяет сравнивать влияние координат при одинаковом покрытии. Пороги детектора сохранены.

На статической записи каждое событие ложно: все отражения пришли от стен. На записи с цилиндром событие отнесено к цели, если оно подтверждено после её появления и его средний центр находится в пределах 0,45 м от центра цилиндра. При ошибочной позе след самого цилиндра также может оказаться за этим допуском. Число сканов с группами учитывает кандидатов до подтверждения; число сканов подтверждения считает разные метки третьего наблюдения.

| Seed, обзор, сцена | matched / 100 | RMSE штатной позы на matched, см | Штатные события у цели / вне цели | Истинные позы, у цели / вне цели | Смещение +45 см, у цели / вне цели |
|---|---:|---:|---:|---:|---:|
| 53, полный, стены | 100 | 4,00 | 0 / 0 | 0 / 0 | 0 / 37 |
| 97, полный, стены | 100 | 3,72 | 0 / 0 | 0 / 0 | 0 / 36 |
| 53, короткий, стены | 46 | 6,51 | 0 / 0 | 0 / 0 | 0 / 1 |
| 97, короткий, стены | 45 | 4,28 | 0 / 0 | 0 / 0 | 0 / 1 |
| 53, полный, цилиндр | 100 | 4,03 | 1 / 0 | 1 / 0 | 1 / 38 |
| 97, полный, цилиндр | 100 | 3,51 | 1 / 0 | 1 / 0 | 0 / 38 |
| 53, короткий, цилиндр | 23 | 100,90 | 0 / 1 | 1 / 0 | 0 / 1 |
| 97, короткий, цилиндр | 21 | 10,97 | 1 / 0 | 1 / 0 | 0 / 1 |

**Стены без нового объекта.** Для штатных и истинных поз ни на одном из 291 доступного скана не было группы-кандидата. При постоянном смещении на полном обзоре группы возникли на 100/100 сканов каждого seed. Для seed 53 получилось 37 ложных событий на 30 разных метках подтверждения, для seed 97 — 36 на 27 метках. На коротком обзоре кандидаты возникли на 15/46 и 14/45 доступных сканов; подтвердилось по одному ложному событию на одной метке. Так изолировано влияние смещения координат при тех же отражениях и маске matched.

**Новый цилиндр.** При истинных позах цилиндр дал по одному событию во всех четырёх записях. На коротком обзоре seed 53 штатный результат сместил событие за допуск цели при ошибке позы 1,01 м на 23 доступных сканах. На коротком обзоре seed 97 осталось 21 из 100 сканов, и одно событие попало в допуск. Частота ложных событий на двух seeds характеризует только этот маршрут, карту и выбранное смещение.

В дополнительной проверке четыре штатные траектории, полученные при наличии цилиндра, подставлены к парным записям с одними стенами. При тех же позах и метках во всех четырёх случаях было ноль событий. Для seed 53 при коротком обзоре это отличает ошибку размещения реальной цели от ложного события, вызванного одними стенами. При истинной и штатной позах событие подтверждено в 257,935 с на тех же 23 наблюдениях; центры составили (1,37; 1,89) и (1,89; 1,31) м соответственно.

Для повторения укажите новый каталог. Исходные ROS 2 bags, траектории, 24 основных и четыре дополнительных отчёта сохраняются вместе с итоговым report.json.

```powershell
& .\.venv-mgts\Scripts\python.exe -X utf8 -m tools.obstacle_pose_controls out/office-obstacle-poses
```
