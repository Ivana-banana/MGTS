# Независимый повторный проезд KITTI

Автомобиль KITTI проехал 53,83 м за 10,29 с в кадрах 0–99, затем вернулся к участку. Инспекция 1049–1088 прошла 13,08 м за 4,05 с, движение есть на всех 40 кадрах, поворот на 12. При построении карты поворот есть на 42 кадрах, движение на 95. Пороги и выбор двух интервалов по положению GPS опубликованы [до получения ошибок](https://github.com/Ivana-banana/MGTS/issues/161#issuecomment-7160164836). Параметры на этом маршруте не подбирались.

Штатный планарный ICP принял все последующие сканы обхода, но сильно недооценил перемещение. По полученной карте даже с известного старта инспекция провела весь участок в прогнозе с нулевой скоростью. В слепом поиске ни один уточнённый кандидат не получил достаточной поддержки. Это один автомобильный проезд с выбранным сечением облака. Результат ограничивает перенос вывода о сантиметровой точности HEAP-1 на быстрые движения.

## Данные и повтор

Исходные Velodyne и GPS/INS OXTS записаны совместно. Положение для оценки берётся из OXTS, независимо от лидара. Использованы синхронизированные пары кадров, максимальная разница временных меток в обходе 9,75 мс, в инспекции 9,56 мс. Это добавляет погрешность при движении. Проекция Mercator масштабируется по широте начала и поворачивается по первому курсу IMU. Лидар переводится в систему IMU по заводской калибровке. Оценка планарная. Кинематический контроль использует скорости из той же системы OXTS, что и опорная траектория, поэтому служит сравнением с доступной кинематикой. Измерений колёс здесь нет.

A. Geiger, P. Lenz, C. Stiller, R. Urtasun, *Vision meets Robotics: The KITTI Dataset*, IJRR 2013. [Описание записей](https://www.cvlibs.net/datasets/kitti/raw_data.php) и [лицензия CC BY-NC-SA 3.0](https://www.cvlibs.net/datasets/kitti/). Портал предусматривает вход для загрузки. На момент проверки опубликованные адреса S3 доступны напрямую. Архив записи занимает 4 424 930 450 байт, скрипт читает файлы внутри ZIP. Для нового запуска укажите свободный каталог результата.

```powershell
New-Item -ItemType Directory -Force out/kitti161 | Out-Null
$base = 'https://s3.eu-central-1.amazonaws.com/avg-kitti/raw_data'
curl.exe -fL "$base/2011_09_30_drive_0027/2011_09_30_drive_0027_sync.zip" -o out/kitti161/drive.zip
curl.exe -fL "$base/2011_09_30_calib.zip" -o out/kitti161/calib.zip
& .\.venv-mgts\Scripts\python.exe -m tools.kitti_repeat out/kitti161 out/kitti161-repeat
```
