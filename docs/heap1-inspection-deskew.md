# HEAP-1: компенсация поворота на повторной инспекции

На одних и тех же 60 сканах инспекции (кадры 2560–2619) сравниваются исходные XYZ и поправка координат по штатному гироскопу и времени каждого луча. Для обеих версий заранее выбраны карты prior и both из №96. На обеих включён прогноз скорости обхода. У prior исходные точки обхода, у both компенсированы также точки обхода. Разрешение обеих карт — 8 см. [План до запуска и SHA-256 карт](https://github.com/Ivana-banana/MGTS/issues/102#issuecomment-7148782658) · [Четыре карты №96](heap1-factorial.md)

## Проверка входа

Исходный TAR проверен по SHA-256 закреплённой ревизии. Для 1 045 856 валидных точек совпали байты XYZ в Zarr и ROS 2 bag, для всех 60 сканов совпали число точек, метки записи и заголовка. В bag хранятся только поля XYZ. Времена взяты из отдельного массива time по тем же индексам, после проверки соответствия. Начало каждого оборота приходится на −99,550…−98,177 мс относительно заголовка, конец — на +1,306 мс. По sequence_id 2723–2782 исходным кадрам соответствуют кадры 2559–2618 архива undistorted. Абсолютные времена первых точек двух архивов сходятся в пределах 0,194 мкс. Для локализации использован только исходный архив. [Семантика времени и первоисточники](heap1-point-times.md)

У 58 внутренних кадров есть полное покрытие IMU, максимальный интервал между соседними измерениями — 3,202 мс. Для кадра 2560 не хватает 97,395 мс до начала оборота, для кадра 2619 — 0,413 мс после последней метки IMU. Оба кадра переданы целиком без изменений, политика та же, что для обхода №90. Попарное сравнение сообщений подтвердило изменения в 58 облаках и побайтовое совпадение остальных двух и всех 2362 сообщений IMU. Все метки сохранены. Для покрытых точек медиана длины поправки — 1,15 см, 95-й перцентиль — 22,43 см, максимум — 8,13 м. Это длина поворотной поправки, зависящая от дальности. Перенос, крен и тангаж внутри оборота здесь не оценивались.

## Воспроизведение

Из корня MGTS в Windows PowerShell после подготовки архива №90, данных №80 и карт №96. Выходные bag и каталог результатов должны быть новыми.

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
$run = 'out/heap1-inspection-102'
New-Item -ItemType Directory -Force $run | Out-Null
& $python -m tools.heap1_point_times out/heap1-timing-90/velodyne_points.tar out/heap1-long-80 "$run/gyro" --recording inspection
& $python -m tools.heap1_inspection_deskew out/heap1-long-80 "$run/gyro" out/heap1-factorial-96 "$run/results"
```

В каждом из четырёх слепых поисков все шесть опор отклонены по слабой геометрической поддержке. В симметричном варианте лучший результат на кадре инспекции 50 составил 0,5499697475 при пороге 0,55. Код выхода во всех четырёх случаях — 2. Для delayed нужны как минимум три принятые опоры.

CPT7 прочитан после завершения всех слепых поисков. Контроль с известным стартом получил только первую позу инспекции, после чего сопоставились 60/60 сканов на каждой карте. Компенсация инспекции уменьшила ошибку курса на обеих картах. Изменение ATE XY зависело от карты: улучшение на 2,37 мм для исходного обхода и ухудшение на 2,52 мм для компенсированного. Это одна пара визитов и фиксированный профиль без подстройки времени. Для обоих исходных контролей CSV траектории побайтово совпал с №96. Повтор подготовки исходного эксперимента обхода №90 воспроизвёл все 12 262 ROS-сообщения с теми же метками и байтами.
