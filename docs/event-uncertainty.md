# Чувствительность событий к ошибке позы

Модуль mgts_nav.event_uncertainty повторяет обнаружение на номинальной траектории и на явно заданных сдвигах dx, dy, dyaw в системе карты (м, м, рад). В JSON по каждой зоне есть такты и интервалы confirmed, uncertain, outside и unobserved. Для препятствия необходимо событие на каждой траектории с общим временем подтверждения и разбросом положения до 25 см. Исходы, существующие хотя бы на одной траектории, выводятся с координатами, статусом и номерами гипотез. Отдельно перечисляются сканы без наблюдений.

Проверка использует восемь парных сценариев из №154: два seed, полный или короткий обзор, пустой проход или новый цилиндр. Контрольная величина 45 см заимствована из намеренного смещения старта в этих сценах. Рассмотрены только три дискретные гипотезы dx = 0, ±0,45 м. Эта величина не является гарантированной границей или доверительным интервалом. Диагностика №164 пропускает часть ошибок. Общий дрейф карты и датчиков, поворот и смещение в других направлениях могут лежать вне принятого набора. Дополнительные альтернативы задаются повторением --offset.

| События | Номинал | С альтернативами |
|---|---:|---:|
| Посещения TP / FP / FN | 10 / 1 / 6 | 0 / 0 / 16 |
| Точность / полнота посещений | 90,9% / 62,5% | не определена / 0% |
| Задержка начала верного посещения | 0–1,10 с | нет принятых |
| Неопределённые такты зон из 1600 | 0 | 281 (17,6%) |
| Препятствия TP / FP / FN | 3 / 1 / 1 | 0 / 0 / 4 |
| Точность / полнота препятствий | 75% / 75% | не определена / 0% |
| Неопределённые кандидаты препятствий | 0 из 4 | 290 из 290 |
| Задержка / ошибка центра у верных препятствий | 0,24–6,14 с / 0,18–0,28 м | нет принятых |

Сопоставление посещений использует временное пересечение с одним эталонным интервалом той же зоны. Один объект учитывается один раз на сцену, допустимая ошибка центра 45 см. Сдвиги порождают ложные группы у стен, поэтому число неопределённых кандидатов может намного превышать число физических объектов. При таком наборе альтернатив полный отказ от уверенных событий обходится потерей всей полноты.

Прежние CSV траектории используются напрямую. Восемь прежних JSON препятствий совпали по числу событий с повторным номинальным прогоном. Новый отчёт создаётся в отдельном файле. Для повторения нужен каталог парных записей, создаваемый tools.obstacle_pose_controls.

~~~powershell
& .\.venv-mgts\Scripts\python.exe -m tools.event_uncertainty_trial out/issue154
& .\.venv-mgts\Scripts\python.exe -m mgts_nav.event_uncertainty out/issue154/53-full-object/inspection out/issue154/53-full-object/localized/trajectory.csv out/issue154/map/map.yaml configs/example.json configs/demo-zones.json out/pose-events.json --offset -.45 0 0 --offset .45 0 0
~~~
