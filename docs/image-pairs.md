# Визуальные пары из ректифицированных изображений ROS

`mgts_nav.image_pairs` читает один топик `sensor_msgs/Image` или `sensor_msgs/CompressedImage` и записывает одну строку JSONL для каждой пары соседних кадров. Для несжатого изображения поддержаны `mono8`, `rgb8` и `bgr8`, включая отступ в конце строки. Для сжатого изображения укажите топик с ректифицированными 8-битными серыми или RGB-кадрами JPEG/PNG. Адаптер проверяет кодек по полю format и содержимому, размер по калибровке и frame_id по заголовку. Повреждённые изображения и compressedDepth вызывают ошибку преобразования. Достаточно зависимостей основного проекта.

Для своей камеры укажите размеры ректифицированного кадра в порядке ширина, высота, его оптический frame_id, матрицу K в пикселях и единичный кватернион поворота из оптической системы в базу в порядке x, y, z, w. Пример файла `camera.json` для синтетической проверки:

```json
{"size":[320,240],"frame_id":"optical","K":[[230,0,160],[0,230,120],[0,0,1]],"base_from_camera_xyzw":[-0.5,0.5,-0.5,0.5]}
```

```powershell
python -m mgts_nav.image_pairs data/inspection inspection-pairs.jsonl --topic /rect --calibration camera.json --header-offset-s 0
python -m mgts_nav.solve data/mapping data/inspection --config configs/official.json --inspection-visual-pairs inspection-pairs.jsonl --out result
```

Подставьте путь к своему профилю датчиков. Время каждой точки интервала равно `header.stamp + header_offset_s` в секундах на шкале лидара. Нулевое смещение подходит для уже согласованных часов. Для записи с независимо подтверждёнными границами передайте также `--camera-motion-bound-m` (максимальное перемещение центра камеры за любую соседнюю пару, включая пропуски кадров) и `--min-scene-range-m` (минимальная дальность статических ориентиров). Опущенная граница сохраняется как `null`; в таком режиме пары пригодны для диагностики, а визуальная поправка отклоняется.

Адаптер выделяет до 400 углов и ищет взаимно ближайшие нормированные фрагменты 11×11 пикселей с проверкой различимости совпадения. Он рассчитан на небольшие изменения ракурса между кадрами. Смаз, повторяющийся рисунок, движущиеся объекты и слабая текстура ограничивают точность. Ректификацию и синхронизацию часов выполняют заранее. Допуск пары определяют штатные `vision` и `visual_fusion`.

### Проверка

```powershell
python -m pytest -q -s tests/test_image_pairs.py
```

Тест записывает пиксели в ROS 2 bag, задаёт поворот проективным преобразованием и запускает конвертер через CLI. На цветных кадрах 320×240 с поворотом +2° исходный растр и PNG дали идентичные соответствия и оценку +1,9958° (299 согласованных точек). JPEG с качеством 90 дал +1,9950° (297 точек). Ошибка JPEG составила 0,0050° при допуске 0,15°. Для серого PNG на −2° получено −1,9929°. Однотонный JPEG дал 0 соответствий и отказ `too_few_tracks`. На текстурированных кадрах с пропущенными границами получен отказ `missing_motion_or_range_bound`. Результаты относятся к этим синтетическим изображениям.

### Калибровка из CameraInfo

Если организаторы предоставили поток CameraInfo для ректифицированного изображения полного разрешения, подставьте его имя и кватернион из фактической статической трансформации оптической камеры в базу. Команда ниже показывает порядок аргументов PowerShell; четыре переменные должны содержать измеренные компоненты.

```powershell
python -m mgts_nav.camera_info data/inspection camera.json --topic /camera/camera_info --base-from-camera-xyzw $qx $qy $qz $qw
```

Команда читает весь выбранный топик. В поле K выходного файла попадают первые три столбца P, определяющие проекцию ректифицированного кадра. Для направления луча поворот в базу равен произведению поворота установки камеры и транспонированной матрицы ректификации R. Этот расчёт относится к ориентации лучей из центра выбранной камеры. Адаптер отклоняет обрезку, биннинг и изменение выходной геометрии внутри записи. Передайте полученный файл в image_pairs и выберите соответствующий топик ректифицированных изображений. [Описание полей CameraInfo в ROS](https://github.com/ros2/common_interfaces/blob/rolling/sensor_msgs/msg/CameraInfo.msg)
