# Независимая регистрация на офисе и KITTI

Trimesh 4.5.3 (MIT) реализует классический point-to-point ICP. В обе реализации переданы одни и те же планарные точки, фиксированная карта MGTS и предыдущая оценка позы. Офисная карта построена штатной репетицией. Кинематический прогноз при сравнении регистраций отключён. Облака для Trimesh дополнены нулевой координатой Z. Проверка на асимметричном облаке восстанавливает перенос (0,04; −0,03) м и поворот 0,025 рад с допуском 1e-8. Ручной привязки нет. [Протокол и бюджеты](https://github.com/Ivana-banana/MGTS/issues/176#issuecomment-7160192623) · [Реализация ICP](https://github.com/mikedh/trimesh/blob/4.5.3/trimesh/registration.py).

| Маршрут, старт | Метод | ATE, м | RPE, м / рад за шаг | RMSE курса, рад | Время / CPU, с |
|---|---|---:|---:|---:|---:|
| Офис, известный | MGTS | 0,0255 | 0,0119 / 0,00225 | 0,0107 | 0,86 / 0,86 |
| | Trimesh | 0,0703 | 0,0253 / 0,00420 | 0,0180 | 0,58 / 0,55 |
| Офис, слепой | MGTS | 0,0254 | 0,0120 / 0,00228 | 0,0107 | 0,89 / 0,89 |
| | Trimesh | 0,0703 | 0,0254 / 0,00420 | 0,0179 | 0,54 / 0,53 |
| KITTI, известный | MGTS | 7,970 | 0,341 / 0,01293 | 0,1037 | 0,05 / 0,06 |
| | Trimesh | 0,828 | 0,247 / 0,01374 | 0,0729 | 0,40 / 0,39 |

Офисный слепой поиск занял ещё 0,51 с. На KITTI оба метода получили отказ общего поиска за 0,95 с, поэтому покрытие слепого режима 0/40. Покрытие по времени во всех строках таблицы полное. При известном старте на KITTI штатная проверка отклонила все 40 сопоставлений, Trimesh выдавал позу на каждом кадре без проверки поддержки. На офисе MGTS принял все 100 сопоставлений. Trimesh уменьшил ATE на этом автомобильном отрезке, но дал более высокую ошибку в офисе. Времена относятся к одному запуску на общей машине.

## Воспроизведение

Сначала подготовьте полевой результат по [инструкции KITTI](kitti-repeat.md). Ниже отдельная установка зависимости для эксперимента и синтетическая репетиция с seed 17.

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m mgts_nav.rehearse out/my-first-demo
& $python -m pip install --no-deps --target out/issue176-lib trimesh==4.5.3
$env:PYTHONPATH = (Resolve-Path out/issue176-lib).Path
& $python -m tools.independent_icp out/my-first-demo out/kitti161 out/kitti161-repeat out/issue176-scores.json
```
