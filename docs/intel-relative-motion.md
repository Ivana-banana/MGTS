# Intel Lab — относительное движение на инспекции

На записи из [опыта №107](intel-lab.md) расхождение появляется уже через 7,26 с. За это время опубликованный RBPF оценивает продвижение вперёд на 0,985 м, локализация на готовой карте даёт смещение назад на 0,416 м, а последовательное сопоставление сканов в отдельном запуске map даёт продвижение всего на 0,106 м.

В таблице каждая тройка — продольное и поперечное перемещения в метрах и изменение курса в градусах относительно первой позы **своего** метода. Все четыре времени в точности присутствуют во всех CSV. Эта проверка исключает постоянное различие начальных поз и обходится без интерполяции и подгонки.

| С начала, с | Внешний RBPF | localize на карте обхода | map только на инспекции |
|---:|---:|---:|---:|
| 0,000 | 0 / 0 / 0 | 0 / 0 / 0 | 0 / 0 / 0 |
| 7,257 | 0,985 / 0,014 / 0,63 | −0,416 / −0,231 / 1,82 | 0,106 / −0,084 / 0,29 |
| 10,999 | 1,981 / 0,185 / 10,38 | −0,623 / −0,240 / 13,91 | 0,152 / −0,013 / 10,91 |
| 14,645 | 2,990 / 0,316 / 6,74 | −0,610 / −0,250 / 11,97 | 0,083 / 0,011 / 7,44 |

У localize все 60 сканов имеют статус matched. У map первый скан задаёт начало, остальные 59 также имеют статус matched. На последней общей метке курс отдельного map отличается от RBPF на 0,70°, хотя продольные перемещения различаются на 2,91 м. Значит, расхождение по переносу воспроизводится и без карты предыдущего обхода. Причина и абсолютная точность по этим четырём позам остаются неизвестными. Внешний RBPF использует тот же лазер. Последняя общая метка предшествует концу инспекции на 0,81 с.

## Повтор в PowerShell

Подготовьте исходные данные и выполните известный старт по [командам №107](intel-lab.md). Из корня репозитория запустите в новый каталог:

```powershell
$p = '.\.venv-mgts\Scripts\python.exe'
& $p -m mgts_nav map out/intel107/data/inspection --config out/intel107/data/profile.json --resolution .08 --out out/intel110/local
@'
from math import degrees
from mgts_nav.metrics import read_csv, relative_pose

rbpf = read_csv("out/intel107/data/inspection-external.csv")
fixed = read_csv("out/intel107/known/trajectory.csv")
local = read_csv("out/intel110/local/trajectory.csv")
for ref in rbpf:
    row = []
    for track in (rbpf, fixed, local):
        pose = next(p for p in track if p.t == ref.t)
        x, y, angle = relative_pose(track[0], pose)
        row.append((round(x, 3), round(y, 3), round(degrees(angle), 2)))
    print(round(ref.t - rbpf[0].t, 3), row)
'@ | & $p -
```

Для опубликованного прогона внешний CSV взят из повторной выгрузки №107 (`data-repeat`). SHA-256 базы inspection.db3 в обеих выгрузках совпал: `e209c70065055ffe7afb16508906468066fea73f07868db6d1f721bb224f615f`.
