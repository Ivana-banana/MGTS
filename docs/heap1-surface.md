# Проверка сглаживания стен на четырёх окнах HEAP‑1

Предложенный в [PR №43](https://github.com/Ivana-banana/MGTS/pull/43) способ заменяет центры занятых клеток средними координатами ближайших занятых соседей. На четырёх полевых окнах по 60 сканов сглаживание уменьшило ошибку приращений между сканами и увеличило абсолютную ошибку траектории относительно CPT7. Доля привязанных сканов у обоих вариантов составила 240/240.

| Первый кадр | ATE XY, см | RPE перемещения, см | Средняя ошибка по Y карты, см | Время, с |
|---|---:|---:|---:|---:|
| 2560 | 4,75 → 4,90 | 2,31 → 1,57 | −2,87 → −3,46 | 0,76 → 0,63 |
| 2620 | 4,13 → 4,77 | 1,03 → 0,79 | −2,81 → −3,49 | 0,52 → 0,47 |
| 2680 | 2,89 → 3,24 | 1,01 → 0,78 | −1,29 → −2,00 | 0,56 → 0,46 |
| 2740 | 3,10 → 3,25 | 1,02 → 0,73 | −2,51 → −2,85 | 0,52 → 0,42 |

В каждой паре слева указан штатный вариант с центрами клеток, справа — сглаженная поверхность. Наибольший прирост ATE — 0,64 см. Оба варианта получили одну и ту же карту 8 см и первую позу каждого окна из внешней GNSS/INS CPT7. Остальные позы CPT7 использованы только при подсчёте метрик. Время — медиана трёх чередующихся прогонов от подготовки точек карты до завершения трекинга, включая создание дерева поиска. Во время сравнения запись находилась в памяти. JSON дополнительно содержит RPE курса, среднее смещение по X и отдельные замеры времени.

Код `surface_points` взят из [коммита предложения](https://github.com/Ivana-banana/MGTS/blob/d1209824e1868a9ff840ec621f616cb9ab4058e5/mgts_nav/slam.py). При проверке синтаксическое дерево функции совпало с той ревизией. Обработка ICP и построение карты взяты из MGTS. Окно 2560 включает поворот, три последующих окна охватывают почти неподвижную часть того же визита. Эти числа дополняют офисный эксперимент автора и показывают компромисс на одном независимом публичном источнике. Скрипт теперь также считает вариант `projection`: проекцию на стену с проверкой наблюдаемости, которую включает `localize --wall-surface`. Таблица выше относится только к первой версии. Для `projection` на HEAP-1 результатов пока нет, см. [accuracy-experiment.md](accuracy-experiment.md).
