# Трёхмерный показ инспекции Go2 по позам и суставам (#213)

Презентационный ролик по выходному bag официального прогона `a5ad606`. Модель Unitree Go2 движется по опубликованным позам `/mgts/pose3d`. Углы всех 12 суставов взяты из измерений `/lowstate` той же инспекции. Стены построены из ячеек карты обхода `map.npz`. Это не захват RViz: ракурсы непосредственно из RViz см. в [go2-video.md](go2-video.md).

## Что на экране

- Камера следует за роботом почти сверху (−72°, 6,5 м). Воспроизведение 1×, 30 кадров/с, 1920 × 1080.
- Красная линия на полу — пройденный путь по опубликованным позам, красная стрелка — направление движения.
- Серые блоки — стены и предметы из наблюдённых ячеек карты обхода 0,12 м, срез 0,5 м над полом. Проёмы и неизвестные области остаются пустыми.
- Справа внизу вид сверху с пройденным путём и положением робота.
- В конце отдельный фрагмент с синей плашкой «МОДЕЛЬНЫЙ СЦЕНАРИЙ #212 — не измерение»: объезд ящика 0,5 × 0,5 м из [go2-obstacle-demo.md](go2-obstacle-demo.md). Ящик задан вручную, робот его не видел. Для этого фрагмента позы не измерены, поэтому походка — повтор измеренного фрагмента `/lowstate`.

**Лицензия модели.** BSD-3-Clause, © 2016–2022 HangZhou YuShu Technology (Unitree Robotics); MJCF получен в Menagerie из публичного URDF Unitree. Файл `LICENSE` лежит рядом с моделью. В репозиторий модель не копируется.

**Время.** Позы результата несут метки заголовков исходных сканов. У `LowState` нет Header, есть только время записи MCAP. Его переводим на шкалу заголовков через пары (получение, заголовок) одометрии `/utlidar/robot_odom` той же записи: смещение 80,826–80,833 с на 16 421 паре, интерполяция по времени получения. Каждому кадру берётся ближайший отсчёт `LowState` (500 Гц): расхождение не больше 1,2 мс. Между позами (≈13,9 Гц) положение интерполируется линейно, ориентация — slerp. Первый скан без позы в ролик не входит.

**Порядок моторов.** `LowState` хранит ноги в порядке FR, FL, RR, RL, модель — FL, FR, RL, RR. Порядок проверен на этой записи. При положительном крене IMU (левый борт выше) левые опорные ноги длиннее правых: корреляция +0,34; при обратном порядке −0,34. Если нос опущен, передние ноги короче (−0,21). Бедра диагональных ног FR и RL синфазны (0,72). Перестановку проверяет `tests/test_go2_show3d.py`.

**Пол.** Высота пола получена из прямой кинематики: опубликованная поза корпуса плюс измеренные суставы, нижняя лапа, медиана по 1524 позам. Получилось z = −0,044 м. Медиана точек карты у маршрута ниже пол + 0,25 м равна −0,011 м. Нижняя лапа относительно пола: p5 −0,044, p50 0,000, p95 +0,017 м. Поэтому на части кадров лапа уходит в пол до 4 см. Высоту корпуса мы не подгоняли.

## Воспроизведение

Из корня MGTS в окружении проекта. Нужны FFmpeg и `mujoco` (проверено 4.0.1, рендер через EGL на Linux).

```bash
uv pip install --python .venv/bin/python mujoco==4.0.1
gh release download mgts-data-2026-11-26 -D out/go2-release -p go2-live-full-a5ad606.zip
(cd out/go2-release && unzip -o go2-live-full-a5ad606.zip)
git clone --filter=blob:none --sparse https://github.com/google-deepmind/mujoco_menagerie.git out/issue213/menagerie
git -C out/issue213/menagerie sparse-checkout set unitree_go2
git -C out/issue213/menagerie checkout eea4c7431b63da8278b0ff31638e0b0e941cec0e
PYTHONPATH=. python -m tools.go2_show3d --still 30 52
```

Команда пишет `out/issue213/show/go2-show3d-a5ad606.mp4`, контрольные кадры `still-*.png` и `manifest.json` со всеми числами выше и хешами источников. Проверка логики: `python -m pytest tests/test_go2_show3d.py`.

## Ограничения

- Видео модельное: корпус и лапы нарисованы по позам и углам суставов. Контакт с полом и проскальзывание не моделируются.
- Стены — воксели одной карты обхода без сглаживания. Мебель и шум выглядят такими же блоками.
- Модельный фрагмент #212 не является результатом локализации или автономного вождения.
