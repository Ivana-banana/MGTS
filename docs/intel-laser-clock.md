# Временные метки FLASER в журнале Intel Lab

Стабильная сортировка по метке IPC вернула 119 сканов обхода и 18 сканов инспекции при тех же начальных и конечных временах. Все эти строки присутствуют в исходном журнале. Адаптер №107 пропускал их при последовательном чтении после строки с более поздней меткой. Физическую причину перестановки строк или потери пакетов до записи по двум полям журнала установить не удалось. [План до анализа](https://github.com/Ivana-banana/MGTS/issues/109#issuecomment-7149095167)

Исходный `intel.log.gz` проверен по SHA-256 адаптера №107. Во всех 13 631 сообщениях FLASER разность IPC и logger равна **976052857,337284 с** с точностью исходной десятичной записи. Оба поля дают один и тот же порядок, включая 631 обратный переход между соседними строками. Максимальное отставание текущей метки от максимума предыдущих — 0,897325 с. Это величина нарушения порядка файла. Задержка доставки до регистратора по этим данным отдельно не измеряется. Документация CARMEN различает метку сообщения и относительное время приёма в регистраторе. [Формат CARMEN](https://carmen.sourceforge.net/doc/group__logger.html) · [Происхождение данных](intel-lab.md)

Ни одна метка IPC не повторилась. Соответственно, групп дубликатов с одинаковыми дальностями — 0, с разными — 0. На случай повтора протокол сохраняет первую строку исходного файла для каждой метки. Отдельный тест проверяет это правило как при одинаковых, так и при различных измерениях.

| Показатель | Обход | Инспекция |
|---|---:|---:|
| Строки FLASER, с нуля включительно | 169–1111 | 3420–3497 |
| Инверсии между соседними строками | 47 | 7 |
| Макс. отставание от предыдущего максимума IPC, с | 0,787713 | 0,758780 |
| Сохранённые сканы, исходный порядок → сортировка | 824 → 943 | 60 → 78 |
| Мин. число пригодных лучей в возвращённом скане | 133 | 156 |
| Максимальный интервал между сохранёнными сканами, с | 1,200164 → 0,944634 | 1,139630 → 0,683285 |
| Число интервалов свыше 0,35 с | 214 → 214 | 20 → 19 |
| Покрытие времени интервалами до 0,35 с | 39,49% → 47,55% | 19,26% → 39,70% |

Покрытие — суммарная длительность промежутков до 0,35 с включительно, делённая на длительность от первой до последней метки окна. Порог взят из проверки цепочки сканов в `delayed`. Включены только лучи с конечной дальностью строго между 0 и 20 м.

На неизменной карте №107 оба ROS bag инспекции дали отказ штатного `delayed` до первой глобальной опоры. В первых 51 сканах сортировка сократила число разрывов свыше 0,35 с с 17 до 11, максимальный интервал — с 1,139630 до 0,598176 с. Пропущенные измерения внутри оставшихся интервалов не синтезировались.
