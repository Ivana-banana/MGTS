# Предупреждение о дрейфе на независимых окнах

На трёх отложенных окнах HEAP-1 добавление геометрии, невязки и гироскопа к порогу поддержки сохранило все решения исходного правила. На длинной карте пропущены 80 из 179 тактов с большой ошибкой. Каждый из трёх эпизодов обнаружен на первом ошибочном такте. Такой результат совместим с частыми пропусками внутри уже начавшегося эпизода и не подтверждает точность отдельных поз.

Известная стартовая поза используется трекером один раз в начале каждого окна. Правила получают только результат трекера, карту и синхронизированные наблюдения. Эталон используется при подсчёте ошибок. Порог большой ошибки XY равен 20 см. Бюджет ложных тревог составляет один такт в минуту. Минутная частота ниже пересчитана из фактической длительности, около 5,9 с на окно. [Протокол и пороги](https://github.com/Ivana-banana/MGTS/issues/164#issuecomment-7160149036)

Покрытие 60/60 во всех окнах. Счётчик учитывает отдельные сигналы. Одна непрерывная серия может дать несколько ложных тактов. В этой инспекции отсутствует колёсная одометрия. Для синтетического офиса отдельно проверены её записанные приращения, отсутствие и положительный дрейф 0,08 м/с в продольной компоненте. Во всех трёх случаях обе схемы дали 100 TN, полное покрытие и ноль эпизодов. Изменяли канал диагностики при фиксированной траектории. Дрейф за такт мал относительно порога. Общая ошибка карты и датчиков, включая постоянный сдвиг системы координат, может сохранять согласие приращений и геометрии.

## Повторение

Подготовка входов карт описана в [отчёте HEAP-1](public-data.md). Для исходного окна использовать heap1-long-80 вместо heap1-heldout-37. Для короткой карты взять heap1-revisit-map и short в пути траектории. Для карты с прогнозом использовать heap1-velocity-88/map.yaml и траектории long из issue160-velocity-control.

~~~powershell
& .\.venv-mgts\Scripts\python.exe -m tools.drift_warning_trial out/heap1-heldout-37/inspection out/heap1-heldout-37/profile.json out/heap1-long-score-80-repeat/map/map.yaml out/issue160-inputs/long/2620/trajectory.csv out/issue160-inputs/truth/2620.csv
& .\.venv-mgts\Scripts\python.exe -m tools.drift_warning_trial out/session3-eval-v1/data/inspection configs/example.json out/session3-eval-v1/map/map.yaml out/session3-eval-v1/loc/trajectory.csv out/session3-eval-v1/data/inspection_truth.csv --odom drift
~~~
