# Грубый и точный поиск стартовой позы в коридоре

В 12 парных запусках исходный односкановый метод дал 8 верных стартов, 1 ложный и 3 отказа. Экспериментальный поиск дал 8 верных стартов и 4 отказа. При дальности 3 м на скане 30 для seed 73 исходный метод ошибся на 5,939 м и 179,43°. Экспериментальный метод отклонил неоднозначную гипотезу. На шести окнах с полным обзором оба метода вернули верные позы.

| Seed | Обзор | Исходный: верно / ложно / отказ | Экспериментальный: верно / ложно / отказ |
|---|---|---:|---:|
| 41 | Полный | 3 / 0 / 0 | 3 / 0 / 0 |
| 41 | До 3 м | 1 / 0 / 2 | 1 / 0 / 2 |
| 73 | Полный | 3 / 0 / 0 | 3 / 0 / 0 |
| 73 | До 3 м | 1 / 1 / 1 | 1 / 0 / 2 |

## По каждому старту

Для принятой позы указаны ошибка положения в метрах и модуль ошибки курса в градусах. Время — один вызов на общей машине. Медиана по 12 окнам составила 0,747 с для исходного и 0,190 с для экспериментального поиска. Генерация данных и построение карт во время поиска не входят.

В известном неоднозначном окне осталось 73 точки. Оценки двух пространственно различных гипотез нового метода составили 0,8666 и 0,8585. Разность меньше действующего допуска 0,045. На идеально симметричном прямоугольнике оба метода отказали. Прямоугольник допускает две геометрически неразличимые позы, связанные поворотом на 180° вокруг его центра.

В каждом из 12 окон исходный поиск вызвал ICP 48 раз, экспериментальный — 32 раза. Экспериментальный поиск оценил 4716 грубых гипотез на каждой карте. На этапе уточнения он оценил 7825–7840 гипотез за вызов. Для прямоугольника — 4500 грубых, 7840 уточняющих и 32 вызова ICP. Эти три счётчика измеряют разные этапы одного поиска.

## Воспроизведение

```powershell
& .\.venv-mgts\Scripts\python.exe -m pytest -q -s tests/test_coarse_corridor.py
```

Команда строит по одной карте с клеткой 8 см из обхода каждого seed и берёт отдельную инспекцию. Оба метода получают одну карту и один скан в каждом сравнении. Маска 3 м считается от положения лидара. При старте кинематика и IMU отключены. Эталон используется для оценки возвращённой позы. Верный старт требует ошибки не выше 0,25 м и 10°. Буквы `icp` в построчном JSON обозначают фактические вызовы регистрации, в исходном методе они посчитаны обёрткой вокруг `match`.

Проверено шесть тестов в локальном Windows PowerShell, SHA-256 исходника экспериментального поиска во время замера — `4ACE1437C3856883385B432A2600C687758FDBB42C8BD3D67DF0C04C54F7D2AC`. Два seed описывают один синтетический коридор. Частоту ложных стартов на других объектах эти наблюдения не определяют.
