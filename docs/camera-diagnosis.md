# Почему выросла ошибка визуального поворота

На участке 4–6 с синтетического офиса основной источник ошибки — перенос оптического центра относительно стены с ориентирами. Оценщик аппроксимирует движение лучей одним вращением. При чистом переносе истинный поворот равен нулю, но даже без пиксельного шума камера дала RMS ложного поворота 0,0830° и 0,0898° за 0,1 с. При чистом вращении без пиксельного шума измерение совпало с эталоном в пределах 0,00001° на обоих seed.

| Движение | Шум, пикс. | RMSE камеры, ° (41 / 73) | Среднее «оценка − истина», ° (41 / 73) |
|---|---:|---:|---:|
| Вращение | 0 | <0,00001 / <0,00001 | ≈0 / ≈0 |
| Вращение | 0,15 | 0,00590 / 0,00299 | −0,00023 / +0,00056 |
| Перенос | 0 | 0,08298 / 0,08977 | −0,01012 / −0,03035 |
| Перенос | 0,15 | 0,08275 / 0,08975 | −0,00987 / −0,02986 |
| Совместное | 0 | 0,08298 / 0,09036 | −0,01012 / −0,03087 |
| Совместное | 0,15 | 0,08270 / 0,09034 | −0,00987 / −0,03033 |

Для смешанного движения и шума 0,15 пикселя получили следующие ошибки **фактического прогноза**. Значения — RMSE приращения угла в градусах за один интервал лидара. Во всех сравнениях использованы одни и те же 19 интервалов.

| IMU | Без камеры (41 / 73) | С камерой (41 / 73) | Источник визуальной поправки на 19 интервалах |
|---|---:|---:|---|
| Всегда доступна | 0,00632 / 0,00642 | 0,01572 / 0,01766 | 15 смешиваний, на 4 интервалах сохранён гироскоп |
| Пропуск как в исходном опыте | 0,03229 / 0,03212 | 0,06459 / 0,07669 | 7 смешиваний, 8 замен отсутствующего гироскопа, 4 интервала без визуальной поправки |
| Отключена | 0,04015 / 0,04015 | 0,07576 / 0,08235 | 15 замен гироскопа, на 4 интервалах использована кинематика |

Режим с пропуском воспроизвёл оба результата из опыта со штатным `solve`. На этой сцене дополнительная ошибка уже видна в выходе камеры до переключения источника. Попадание этого сигнала в прогноз особенно заметно при отсутствии гироскопа. Вывод ограничен одной геометрией, скоростью движения и двумя реализациями шума. Новый критерий принятия пар в этом эксперименте не вводился.

## Методика и воспроизведение

Симулятор сохраняет траекторию исходного опыта или фиксирует координаты центра камеры либо угол на значении в середине окна. Затем заново генерирует измерения IMU, одометрии и камерных пар. Маркеры, пропуски треков, ложные соответствия и вырожденный участок сцены сохранены. Пиксельный шум меняется с 0 до 0,15 пикселя. Сравниваются постоянная доступность гироскопа, его штатный пропуск с 4,8 с и полное отключение. В режиме отключения удаляется только измеренное приращение гироскопа. Прогноз вычисляют производственные функции `apply_visual` и `predict`. Истинный угол используется только в симуляторе и при подсчёте ошибок.

```powershell
& .\.venv-mgts\Scripts\python.exe -m tools.diagnose_camera out/camera-diagnosis-new --seeds 41 73
```

Команда требует новый выходной каталог. [Полная таблица для 36 конфигураций](camera-diagnosis.csv) содержит число принятых пар, число интервалов, среднюю знаковую ошибку и RMSE каждого источника. Суффикс `_n` задаёт числитель покрытия, знаменатель — `intervals`. Метрики источников вычислены по их доступным интервалам; столбцы `baseline` и `fused` охватывают все интервалы. Камера приняла 65 из 76 пар в каждом опыте. Для 15 из 19 интервалов были доступны все четыре пары. При штатном пропуске гироскоп покрыл 7 из 19 интервалов, кинематика — все 19.
