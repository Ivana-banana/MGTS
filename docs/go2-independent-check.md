# Независимая проверка на инспекции Go2

На общем участке 1 524 сканов медианное расстояние контрольных точек до воксельной карты составило 5,41 см у 3D-трекера и 5,68 см у штатной одометрии. На проверенном возврате облака, напротив, лучше совпали у одометрии. Независимой разметки положения робота в этих файлах нет. По ним можно проверить внутреннюю согласованность и обнаружить крупные расхождения. Для оценки ATE и RPE нужен внешний эталон.

## Условия сравнения

[Окна, пороги и выбор возвратов](https://github.com/Ivana-banana/MGTS/issues/185#issuecomment-7186186442) опубликованы до расчётов. Использованы официальный обход и инспекция из [релиза](https://github.com/Ivana-banana/MGTS/releases/tag/mgts-data-2026-11-26), профиль configs/go2-official.json и [выходной bag прогона a5ad606](https://github.com/Ivana-banana/MGTS/releases/download/mgts-data-2026-11-26/go2-live-full-a5ad606.zip). Ядро локализации на проверяемом коммите a5ad606167c82d7d462a3de9dc2fae889315cf06. 2D-карта, независимо пересобранная по 1 688 сканам, побайтно совпала с исходной PGM. Её SHA-256 начинается с 219c86b854a88c7c, SHA-256 map.npz — с a11f1018e944ea1a.

Старт для всех методов взят в момент первого общего скана, через 0,0779 с после первого входного. Для 2D начальная поза в кадре его карты равна (0,68851 м; −0,08860 м; 0,36243 рад). Началу двумерной карты присвоена ближайшая поза одометрии обхода, полученная через 87,35 мс после первого скана обхода. У 3D старт и первая выданная поза совпадают с одометрией. 2D на первом скане внёс поправку 0,402 м и −5,80°. После старта координаты траекторий не подгонялись. Для пространственной проверки 2D дополнен высотой, креном и тангажом одометрии.

В 2D на всех позах, включая прогнозные, порог расстояния превышен на 489 сканах, порог скачка — на 16. У 3D и одометрии оба счётчика равны нулю. Истинная частота ложных привязок неизвестна. Метрика чувствительна к геометрии карты, неподвижности сцены и общему одометрическому кадру. На последнем окне все 151 поза 2D прогнозные; их расхождение с объёмной картой достигло десятков метров.

## Повторное наблюдение

Отбор по одометрии дал четыре пары. Ранний скан во всех парах один, на 62,05 с, поздние идут с 78,05 до 81,05 с. Для каждой пары измерена медиана ближайших расстояний в обе стороны между контрольными точками двух сканов, затем два направления усреднены. Медиана по четырём парам у одометрии **7,97 см**, у 3D **11,73 см**, у 2D **240,15 см**. На всех четырёх парах остаток 3D больше одометрического. Это один эпизод. Отбор по близости одометрических поз может благоприятствовать одометрии, а результат зависит от видимой части сцены. Дополнительная [проверка контуров карты обхода](https://github.com/Ivana-banana/MGTS/issues/183#issuecomment-7186236043) относится к другой паре наблюдений.

## Воспроизведение

Из корня MGTS в проектном окружении. Для новой копии карты и проверки исполните команды ниже. Каталоги live-full и full3d относятся к [прогону #197](https://github.com/Ivana-banana/MGTS/issues/197#issuecomment-7186009229). В отчёте JSON перечисляются отдельные пары возврата и все счётчики.

~~~~powershell
python -m mgts_nav map data/official/mapping --config configs/go2-official.json --out out/issue185-independent/rebuilt-map
python -m tools.go2_independent_check data/official/mapping data/official/inspection configs/go2-official.json out/issue185-independent/rebuilt-map/map.yaml out/issue197/full3d/map.npz out/issue197/live-full/result out/issue197/live-full/timings.csv
~~~~
