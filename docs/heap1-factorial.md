# HEAP-1: совместная проверка поворотной компенсации и прогноза скорости

Проверены четыре сочетания двух изменений обхода. Первое приводит точки каждого оборота к времени заголовка по штатному гироскопу и временам отдельных лучей. Второе включает ограниченный прогноз переноса по скорости двух последних подтверждённых поз обхода. Режимы используют одинаковую сетку 8 см и настройки ICP. Опорная поза начала обхода во всех случаях равна (0, 0, 0). [Времена точек и компенсация](heap1-point-times.md) · [Прогноз скорости](heap1-velocity-prior.md)

Для каждого сочетания штатная команда map получила те же кадры 150–449, а localize с поиском delayed — одни и те же исходные 60 сканов 2560–2619. Это асимметричная проверка: компенсация затрагивает только обход. У двух крайних сканов обхода недостаточно покрытия IMU, поэтому даже в вариантах с компенсацией их XYZ исходные. Прогноз скорости также применяется только при построении карты.

CPT7 прочитан после построения всех карт и всех слепых поисков. Отдельный контроль получает первую опорную позу инспекции как --initial. Остальные опорные позы используются только для оценки. ATE — среднеквадратичная ошибка XY в системе начала карты без подгонки. Для кадров 220–230 сравниваются векторы перемещения в осях корпуса в начале интервала.

## Воспроизведение

Из корня MGTS в Windows PowerShell, после подготовки исходных bag по №80 и компенсированного bag по №90. Команда создаёт новый каталог, четыре карты, результаты инспекций и scores.json с диагностикой каждого слепого поиска.

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m tools.heap1_factorial out/heap1-long-80 out/heap1-timing-90/gyro out/heap1-factorial-96
```

В сочетании методов ошибка локального перемещения минимальна. На всём обходе минимальные ATE и финальная ошибка получены с одним прогнозом скорости. Добавление компенсации к прогнозу подняло финальную ошибку на 0,86 см. На инспекции с известным стартом два этих варианта дали ATE 6,288 и 6,293 см соответственно.

На четырёх картах после начального кадра приняты 299/299 привязок обхода. В режимах с прогнозом он использован 297 раз. С известным стартом приняты все 60 сканов инспекции на каждой карте. При слепом старте ни одна из шести опор на каждой карте не достигла порога поддержки 0,55. Код отказа delayed во всех случаях — 2, слепая траектория отсутствует.

Три контрольные траектории обхода побайтово совпали с прежними результатами №80, №88 и №90 соответственно. SHA-256 исходного inspection.db3 во всех запусках — 4b90cde0ee0a1c5de7ec79c606a5c2883cd33a92b9bbf33932d9329c3151dfaf. Оценки относятся к одной миссии, одной паре окон и исходным точкам повторной инспекции.
