# Ошибка установки лидара в профилях обхода и инспекции

На синтетическом офисе все 100 сканов инспекции получили статус matched во всех 14 прогонах. При ошибке установки +5° в обоих профилях ATE корпуса при инспекции выросла с 3,83–3,90 до 13,06–13,67 см, а 69,5% занятых клеток карты оказались дальше 12 см от ближайшей статической стены. Доля matched сама по себе не выявила эту ошибку.

## Условия

До измерений в №46 зафиксированы seed 41 и 73, разрешение 0,08 м и допуск стен 0,12 м. Для каждого seed генератор создаёт одну пару ROS 2 bag с правильной установкой. Затем меняется только профиль их обработки. Поворот +5° вокруг оси z корпуса применяется слева к повороту из лидара в корпус. Перенос добавляет 0,10 м к координате x установки в корпусе. Для комбинированного случая изменены оба параметра. Контрольная карта каждого seed повторно используется во всех вариантах, где отличается только профиль инспекции.

Штатные map и localize получают общий для вариантов известный старт своего маршрута. Траектории сравниваются в системе обхода без подгонки по эталону. ATE — среднеквадратичная ошибка XY корпуса, ошибка курса — RMSE кратчайшей угловой разности. Геометрия карты оценивается по центрам занятых клеток относительно статических отрезков офиса. В сцене есть штатная движущаяся помеха. Покрытие стен взвешено по длине.

## Измерения

В каждой ячейке значения для seed **41 / 73**. В каждом обходе 199/200 сканов имели статус matched (99,5%), первый имел статус origin. В каждой инспекции matched получили 100/100. С временным эталоном сопоставлены все позы.

| Контроль | Оба | 0,73 / 0,68 | 10,67 / 10,92 | 4,85 / 4,86 | 0 / 0 | 88,9 / 89,3 |

Ошибка +5° только при инспекции снизила ATE XY на этих записях, но дала ошибку курса почти 5°. При той же ошибке в обеих записях курс инспекции оказался близок к эталону, хотя геометрия карты и положение корпуса ухудшились. Один показатель совпадения сканов или одна координатная метрика оставляют часть ошибки незамеченной. Эти результаты относятся к двум реализациям шума в одном офисе, к заданным возмущениям и известному старту.

## Воспроизведение

Из корня MGTS в Windows PowerShell, с новым каталогом результата:

```powershell
& .\.venv-mgts\Scripts\python.exe -m tools.evaluate_lidar_extrinsics out/extrinsics-46
```

В каталоге будут четыре профиля, обе исходные пары bag, карты, траектории и results.json с 14 строками. ATE в JSON записана в метрах, доли геометрических показателей — от 0 до 1. Воспроизведение не требует официальных записей.
