# Диагностика часов по окнам

Команда сравнивает независимую оценку угловой скорости по лидару с рядом IMU или одометрии. В двух CSV нужны t (время заголовка в секундах) и rate (угловая скорость корпуса, рад/с). Положительная оценка означает, что метки датчика опережают метки лидара по численному значению. Для приведения времени датчика к лидару эту оценку вычитают.

Поиск в каждом полном окне 5 с охватывает ±0,5 с с шагом 5 мс. Разрывы исходного ряда более 160 мс исключены из интерполяции. Для оценки нужны 80% совместных отсчётов, стандартное отклонение обоих сигналов от 0,035 рад/с, корреляция от 0,8 и отрыв от удалённого пика. Скачок — разница более 80 мс между соседними пригодными окнами. Отдельные сегменты длиной от трёх окон классифицируются по порогу наклона 1 мс/с. В JSON сохраняются границы, качество, знаковая задержка и причины отказа. Неполное последнее окно отбрасывается. При обратном ходе меток требуется разрезать запись в месте сброса и отдельно установить эпоху каждого сегмента.

## Парные записи

60 с моделируемого движения, независимые частоты выборки лидара 10 Гц, IMU 50 Гц и кинематики 20 Гц. Лидарный ряд получен дифференцированием измерений курса, гироскоп даёт угловую скорость, кинематический ряд использует производную курса одометрии. Это контролируемые записи сигналов без ошибок измерения. В 10–15 с сообщения сравниваемого датчика пропущены, в 20–30 с движение отсутствует. В каждом опыте получено 9 пригодных окон, одно окно с недостаточным покрытием и два со слабым движением. Исходные метки остаются в CSV. Расчёт с поправкой включается только флагом --apply-estimated и оценивает позиции одометрии на одинаковых внутренних метках пригодных окон.

| Внесённая неисправность | Максимальная ошибка задержки IMU / одометрии | Ошибка границы | Ложные скачки | ATE одометрии до / после, м |
|---|---:|---|---:|---:|
| Постоянные +70 мс | 0 / 0 мс | — | 0 | 0,0442 / 0 |
| +70 мс и 3 мс/с | 2,5 / 2,5 мс | — | 0 | 0,1122 / 0,0028 |
| +70 → +250 мс в 40 с | 0 / 0 мс | 0 с | 0 | 0,1094 / 0 |

На сегменте 30–60 с оценка дрейфа 3,23 мс/с. Скачок внесён на границе окна, что объясняет нулевую ошибку локализации в этом контроле. При скачке внутри окна граница дискретизируется по окнам, отсутствие поворотов делает сдвиг по этому каналу ненаблюдаемым.

## Публичная запись

На 300 сканах обхода HEAP-1 независимые угловые приращения получены парной регистрацией соседних облаков без IMU и кинематики. В пяти полных окнах оценки по гироскопу составили −30, −45, −45, −45 и −25 мс. Оценка наклона 0,20 мс/с, классификация постоянного сдвига, обнаруженных скачков 0.
