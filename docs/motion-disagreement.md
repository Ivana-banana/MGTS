# Расхождение относительного движения на окнах по одной секунде

Сравнение локализации с кинематикой и IMU обнаружило 4 из 11 эпизодов большой ошибки на 24 синтетических инспекциях. В коридоре с обзором 3 м алгоритм мог принять все 100 сканов и пропустить ошибку. Это диагностика несогласия измерений; абсолютную позу и источник сбоя по одному сигналу определить нельзя.

Карта построена на полном обходе с разрешением 8 см; старт инспекции известен. На каждой метке лидара сравниваются векторы смещения корпуса в начальной системе окна по локализации и одометрии. Изменение курса отдельно сравнивается с суммой приращений IMU. Сигнал возникает при разнице больше 0,15 м или 5°. Окну нужна длительность 1 с с допуском 50 мс и непрерывные измерения канала. При отсутствии одометрии остаётся проверка курса. Первые десять меток каждой инспекции не имеют полного окна. Пороги, сценарии и seeds 41/73 зафиксированы [до запуска](https://github.com/Ivana-banana/MGTS/issues/47#issuecomment-7147472092).

Эталон используется после расчёта сигналов. Положительная метка означает абсолютную ошибку корпуса больше 0,25 м или 10°. TP, FP и FN в таблице относятся к этой метке. Так, FP при искусственном дрейфе одометрии может правильно указывать на реальное расхождение датчиков при точной локализации. Каждая строка объединяет две инспекции по 100 сканов; у 180 меток доступен хотя бы один канал диагностики. ATE дан отдельно для seeds 41 и 73.

На обнаруженных эпизодах задержка от первой опасной метки составила 0 и 0 с при скачке одометрии в офисе, 0 и 0,2 с на офисных окнах 3 м без одометрии. Чувствительность по доступным меткам — 48/508 (9,4%), доля ложных сигналов среди остальных — 260/1652 (15,7%). В четырёх здоровых инспекциях ложных сигналов было 0/360. Перекрывающиеся окна статистически зависимы.

Локализатор использует одометрию и гироскоп для прогноза, поэтому проверочные каналы частично связаны с оцениваемой позой. В режиме прогноза траектория может повторить ошибочное смещение одометрии. После постоянного сдвига координат относительные перемещения могут снова совпасть. Без одометрии согласованный курс ничего не говорит об ошибке поступательного движения. Алгоритм диагностики читает готовые позы и не вносит поправок.

## Воспроизведение скрытого ухода из PR №43

Отдельный прогон с теми же порогами использовал все пять офисных seeds автора PR. На полном обзоре все пять инспекций прошли без опасных меток и без сигналов (0/450). При 3 м получены следующие результаты:

| Seed | ATE XY, см | matched из 100 | TP / FP / FN | Задержка |
|---:|---:|---:|---:|---|
| 17 | 61,9 | 100 | 38 / 6 / 22 | 0 с |
| 101 | 4,4 | 90 | 0 / 0 / 0 | Нет опасного эпизода |
| 202 | 60,2 | 98 | 40 / 3 / 22 | 0 с |
| 303 | 59,7 | 97 | 34 / 8 / 25 | 0 с |
| 404 | 60,1 | 97 | 35 / 6 / 25 | 0 с |

Диагностика отметила все четыре эпизода уже на первой метке превышения порога абсолютной ошибки. Внутри этих эпизодов 94 из 241 опасной метки остались без сигнала. Вне эпизодов сработали 23 из 209 доступных окон. Таким образом, сигнал помогает заметить начало именно этого офисного сбоя, но его исчезновение не подтверждает восстановление локализации.

## Повторить в PowerShell

```powershell
python -m tools.evaluate_motion_disagreement out/disagreement-main
python -m tools.evaluate_motion_disagreement out/disagreement-pr --pr-office
python -m pytest -q tests/test_motion_disagreement.py
```

Для каждого запуска требуется новая выходная папка. В `results.json` сохраняются ошибки, исходы, недоступные каналы и времена эпизодов. Файлы `*-windows.json` содержат метки и величины расхождений до сравнения с эталоном. Ограничение 3 м применено к точкам в системе корпуса, как в эксперименте PR №43.
