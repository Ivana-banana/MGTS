# Манифест завершённого solve

Для передачи результата вместе с исходными записями создайте манифест, пока проверяете происхождение входов. В PowerShell из корня MGTS:

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m mgts_nav.solve_manifest create data/mapping data/inspection out/solution out/manifest.json
& $python -m mgts_nav.solve_manifest verify data/mapping data/inspection out/solution out/manifest.json
```

Команде передаются четыре пути: запись обхода, запись инспекции, результат solve и файл манифеста. После переноса передайте новые пути в том же порядке. В манифесте хранятся логические роли и относительные имена. Файл ROS 1 занимает роль recording; для каталога ROS 2 учитываются metadata.yaml и каждый том из relative_file_paths. Для результата учитываются скопированные профили, YAML и изображение карты, траектории, сводки и экспорт RViz. Условные продукты, включая непрерывную траекторию и кинематический baseline, включаются при наличии.

SHA-256 рассчитывается блоками по 1 МиБ. Повторный запуск verify обнаруживает изменение содержимого, пропажу или появление учитываемого файла. При расхождении команда называет файл и завершается с кодом 2. Существующий манифест защищён от перезаписи командой create.

Разрешение карты, способ и начальная поза инспекции берутся из продуктов solve. Для известной версии исходного запуска укажите `--solve-revision VERSION` при создании. В противном случае поле версии остаётся null. Для создания и проверки Git не требуется. Параметры, которые исходный solve не сохранил, восстановить из этих продуктов нельзя. Манифест фиксирует предоставленный набор на момент создания. Ретроспективная проверка не доказывает, что указанные входы действительно использовались в исходном запуске. Для проверки целостности при передаче получателю нужна доверенная копия манифеста.

Проверено на сохранённом деморезультате №1 (seed 73, режим без визуальной поправки): 19 файлов прошли verify. Тест CLI переносит набор в другой каталог, меняет второй том и CSV по отдельности и проверяет код возврата и имя файла:

```powershell
& $python -m pytest -q tests/test_solve_manifest.py
```
