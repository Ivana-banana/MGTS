# Инспекция коридора с изменившейся дверью

На двух генерациях коридора автоматическая локализация дала среднеквадратичную ошибку положения **1,56 и 1,31 см**. Стартовую позу для неё определяли по карте. Кинематическая одометрия, запущенная из тех же двух оценок старта, дала **14,30 и 14,93 см**.

## Условия

Коридор шириной 3,4 м и длиной 11,8 м имеет две асимметричные боковые ниши. Между обходом и инспекцией дверь в одной нише поворачивается. Лидар охватывает 360°, генератор отбрасывает 35 % лучей независимо и добавляет шум дальности. Для каждого seed заново сгенерированы две записи и построена карта с клеткой 8 см. Геометрия и движения одинаковы у двух seed, меняется шум. Обход содержит 200 сканов, отдельная инспекция — 100.

### Среднеквадратичная ошибка положения, см

| Запись и доступные измерения | Старт | Seed 41 | Seed 73 |
|---|---|---:|---:|
| Обход · лидар, IMU, кинематика | Начало карты | 0,99 | 0,88 |
| Обход · только лидар | Начало карты | 3,93 | 3,41 |
| Инспекция · лидар, IMU, кинематика | Известный | 1,55 | 1,31 |
| Инспекция · только лидар | Тот же известный | 2,13 | 2,06 |
| Инспекция · только кинематика | Тот же известный | 15,01 | 15,01 |
| Инспекция · лидар, IMU, кинематика | Автоматический | 1,56 | 1,31 |
| Инспекция · только кинематика | Та же автоматическая оценка | 14,30 | 14,93 |

Во всех инспекциях одного seed использована одна карта полного набора сенсоров. При проверке только лидара трекеру отключали оба источника приращений движения. Отдельная строка обхода показывает, как меняется сама оценка траектории картирования. Кинематика в генераторе имеет детерминированный дрейф, поэтому её результат при известном старте совпадает для обоих seed.

### Отказы и ошибки старта

| Показатель | Seed 41 | Seed 73 |
|---|---:|---:|
| Ошибка автоматического старта по XY, см | 1,21 | 0,31 |
| Ошибка автоматического курса, градусы | 0,009 | 0,050 |
| Сопоставления с картой при автоматическом старте | 100 / 100 | 100 / 100 |
| Сопоставления с картой при известном старте | 100 / 100 | 100 / 100 |
| Инспекционные позы только по прогнозу при работе только лидара | 0 | 0 |

Отказов инициализации в двух запусках не было. Покрытие эталона всех завершённых траекторий составило 100 %. Известный старт инспекции — (2,1 м, 0,3 м, 2,65 рад). Его использовали только в вариантах с заданным стартом и для последующей оценки автоматического старта. Ниши и торцы коридора видны при полном обзоре. Точность в длинном проходе без видимых ориентиров остаётся открытым вопросом.

## Воспроизведение

Из корня проекта запустите `python -m pytest -q -s tests/test_corridor.py`. Команда для каждого seed вызывает генератор (`python -m mgts_nav.demo OUT --layout corridor --seed 41` или `73`), строит карту, запускает локализацию и контрольные варианты, печатает исходные ошибки в метрах и сведения об отказах. Проверено 2 из 2 запусков.

Первые 12 символов SHA-256 исходников прогона: `demo.py DB3AA789066D`, `bag.py CC937A70FEE8`, `slam.py DDDB4D6BF5DA`, `initialization.py 282A9E406CC3`, `multiscan.py BBB3BD3D1487`, `__main__.py B8A094FC2441`.
