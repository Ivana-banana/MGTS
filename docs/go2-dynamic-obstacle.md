# Go2 пропускает пешехода в коридоре

Модельный эпизод длится 9,58 с. На прямом участке карты официального обхода Go2 движется со скоростью 0,45 м/с. Пешеход пересекает коридор со скоростью 0,40 м/с. Go2 останавливается на 1,59 с модельного времени, ждёт 2,40 с и доходит до цели. Положение пешехода задаёт сценарий. Физический робот в этом опыте не участвовал. [Траектории для воспроизведения](go2-dynamic-obstacle.json)

## Результат

| Проверка | Результат |
|---|---:|
| Прямое движение без ожидания | Центры совпадают на 3,59 с |
| Минимальное расстояние между центрами после планирования | 0,718 м на 4,93 с |
| Минимальный зазор между габаритами | 0,118 м при требуемом 0,100 м |
| Зазор от габарита Go2 до занятой клетки, неизвестной области или края карты | 0,677 м |
| Такой же зазор для пешехода | 0,234 м |
| Пешеход остановился на пересечении и остаётся там | Планировщик отказывает в проходе по этой прямой |

Габариты представлены дисками радиусом 0,38 м для Go2 и 0,22 м для пешехода. Планировщик подбирает длительность ожидания в одной точке пути с шагом 0,10 с до 12 с включительно. Начало и конец прямой взяты из [проверки статического объезда](go2-obstacle-demo.md). Траектория человека задана заранее. Здесь проверяется выбор момента прохода. Детекция человека, прогноз по лидару и динамика торможения требуют самостоятельной проверки.

Карта имеет разрешение 0,08 м и SHA-256 `219c86b854a88c7ce7b8fbb391ac4a38e2e5e6464e54ae4cd25a8e074d9c6666` для PGM. Для каждого перемещения вычисляется минимальное расстояние от отрезка до замкнутых квадратов занятых и неизвестных клеток, а также до внешней границы карты. Между сменами скорости проверяется непрерывное относительное движение двух дисков. Так учитываются столкновения между кадрами.

## Воспроизведение

Команды выполняются из корня MGTS в PowerShell. Нужна карта, пересобранная по официальному обходу в [независимой проверке](go2-independent-check.md).

```powershell
& .\.venv-mgts\Scripts\python.exe -m tools.go2_dynamic_obstacle out/issue185-independent/rebuilt-map/map.yaml docs/go2-obstacle-demo.json --out out/go2-dynamic-obstacle/route.json
& .\.venv-mgts\Scripts\python.exe -m pytest -q tests/test_go2_dynamic_obstacle.py tests/test_go2_obstacle_demo.py
```

Для показа используйте одну шкалу `timeline.t_s`. Пары `robot_xy` и `obstacle_xy` заданы в кадре `map2d`. Пары с окончанием `_map3d` переведены одним жёстким преобразованием в кадр официальной 3D-карты. Курс каждого участника постоянен. Интерполируйте координаты линейно между соседними метками. Все моменты остановки и старта входят в шкалу. Стены и мини-план для модельного эпизода берите из указанной PGM.

В синтетическом офисе проекта уже присутствует движущийся цилиндр, который перекрывает лазерные лучи. Это отдельная проверка формирования сканов и карты. [Генератор офиса](../mgts_nav/demo.py) · [Результаты картирования](glass-person.md)
