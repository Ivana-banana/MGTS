# Сдвиг заголовков IMU на офисной инспекции

Воспроизведение из корня MGTS в Windows PowerShell, на стандартном офисе с начальным seed 17:

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m mgts_nav.demo out/clock-demo
& $python -m mgts_nav.clock_experiment out/clock-demo
```

Эксперимент строит карту 8 см по чистому обходу. На временных копиях второй записи меняются только времена в заголовках IMU. Времена доставки, содержимое датчиков и известная стартовая поза для пяти запусков одинаковы. Знак в колонке сдвига означает прибавление к исходному времени IMU. Для компенсации профиль добавляет противоположную величину в `header_offset_s.imu`.

По эталонному изменению курса между соседними лидарами выделены 81 интервал с поворотом и 18 без вращения. Первый скан задаёт начало. ATE и ошибка курса относятся к концу интервала, ошибка шага гироскопа — к его интегралу по доступным данным. Доля сопоставленных сканов в каждой строке составила 100 %.

На повороте сдвиг увеличил ошибку интеграла гироскопа примерно в 14–15 раз. Сопоставление лидара с картой ограничило влияние этого сдвига на конечный курс. На концах записи сдвинутый IMU переставал покрывать часть интервалов. Обе компенсации восстановили исходные x, y и yaw на всех 100 сканах с абсолютным допуском 10⁻⁸ м или рад, совпадение статусов проверено поэлементно. Результат относится к одной синтетической записи и постоянному сдвигу.
