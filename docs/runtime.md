# Время, память и разрешение карты

На синтетической инспекции с известной стартовой позой уменьшение клетки с 8 до 5 см снизило ATE с **3,88 до 3,00 см**. Построение карты на этом ноутбуке заняло дополнительно **3,78 с**, а файл карты вырос с 11 298 до 27 900 байт. При всех трёх разрешениях локализованы 100 из 100 меток инспекции.

## Условия измерения

AMD Ryzen 5 5500U, 12 логических процессоров, Windows 10 build 19044, Python 3.10.10. Использованы одни и те же записи генератора с seeds 17 и 18, профиль `configs/example.json`, обход из 200 сканов и инспекция из 100 сканов. Начальная поза инспекции взята из `initial_pose.json`. Эталон используется для расчёта ATE. Измерялся обычный режим построения карты, без оптимизации по замыканию петли.

Каждая строка включает два последовательно запущенных новых процесса. Время измерено в родительском процессе через `perf_counter` и включает запуск Python, импорт, чтение bag и запись результатов с картинкой. На Windows пик памяти взят из `GetProcessMemoryInfo.PeakWorkingSetSize` текущего дочернего процесса перед выходом. На Linux и macOS команда использует `getrusage(RUSAGE_SELF).ru_maxrss`. Это пик резидентной памяти процесса. Отдельно запущенные процессы, системный файловый кэш и память GPU в него не включены. МиБ равен 1 048 576 байтам. Размер карты в таблице относится к файлу PGM.

Выполнен один проход на каждом разрешении без принудительной очистки кэша, на общей рабочей машине. Разницу времени локализации в десятые доли секунды нужно перепроверить серией повторов перед выбором параметров для официальной записи. Скорость в таблице — средняя за весь офлайн-запуск.

## Воспроизведение

```powershell
python -m mgts_nav.demo out/runtime-data
python -m mgts_nav.benchmark out/runtime-data
```

Для уже сгенерированных записей достаточно второй команды с их каталогом. Она возвращает профиль оборудования и JSON для всех разрешений. Первые 12 знаков SHA-256 файлов данного прогона: `benchmark.py 5A8D22D823E8`, `bag.py CC937A70FEE8`, `grid.py C3DD48C008EA`, `slam.py DDDB4D6BF5DA`, `__main__.py FB417FE8A1AF`.
