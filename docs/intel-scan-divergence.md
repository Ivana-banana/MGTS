# Где расходятся два обхода Intel Lab

В эксперименте №139 преобразование LaserScan с округлением float32 изменило координаты лучей максимум на 2,39 мкм. На кадре 25 выбор других представителей 6-см вокселей дал различие оценки XY уже в 1,14 см при одном и том же прогнозе и дереве соответствий. При замене только этого кадра траектории разошлись к концу обхода на 1,05 м, хотя статусы совпали на всех 824 метках. Величина относится к этой записи и начальной истории трекера.

## Первый участок

Нумерация с нуля. Пороги 1 и 10 см применены к сравнению сохранённых траекторий после расчёта. Исходная поза обеих траекторий одинакова. Из 165 лучей кадра 0 выбраны те же 114 представителей. Для каждого указанного ниже кадра исходное различие координат одноимённых лучей до вокселей не превышало 1,07 мкм.

| Первый случай | Кадр | Полные проходы, расхождение XY | Лучей до вокселей | Представители прямого / LaserScan, из них общих |
|---|---:|---:|---:|---:|
| Ненулевое XY | 1 | 0,0227 мкм | 165 | 116 / 117, общих 116 |
| Более 1 см | 25 | 1,113 см | 176 | 118 / 118, общих 117 |
| Более 10 см | 72 | 14,430 см | 165 | 108 / 108, общих 107 |
| Разные статусы | 751 | 1,106 м | 178 | 126 / 127, общих 126 |

## Контроль входного состояния

Перед каждым выбранным кадром сохранены дерево локальных ключевых кадров и прогноз штатного track. Два облака поданы в штатный match при одном дереве и одном прогнозе. Опыт повторён на истории каждого прохода. По всем 824 меткам воспроизведены точные XY, курс и статусы обоих исходных CSV. Растеризация в повторе пропущена: track строит дерево по ключевым кадрам и только записывает результат в сетку. Эталон RBPF в вычислениях не участвует.

| Кадр | Локальное расхождение XY на прямой истории | На истории LaserScan | Принятые пары на прямой истории, прямой / LaserScan / общие |
|---:|---:|---:|---:|
| 1 | 0,0080 мкм | 0,0080 мкм | 113 / 114 / 113 |
| 25 | 11,438 мм | 0,202 мм | 104 / 104 / 81 |
| 72 | 0,432 мм | 1,144 мм | 103 / 103 / 101 |
| 751 | 0 (два отказа) | 555,857 мм (отказ / принятие) | 0 / 0 / 0 |

Пара определяется индексом исходного луча и индексом ближайшей точки одного фиксированного дерева. Для принятой позы учитывается штатный порог невязки 0,16 м. На кадре 25 при прямом прогнозе (−0,09063 м, −0,06375 м, −1,57857 рад) из 101 начальной пары после отсечения у каждого облака 100 совпали. В итоговой принятой позе общими остались 81 из 104. Если сохранить прямые индексы и заменить только координаты на округлённые, локальное расхождение составляет 0,0144 мкм. Если сохранить прямые координаты и взять индексы и порядок представителей LaserScan, результат меняется на 11,438 мм.

На кадре 72 локальная замена с каждой фиксированной историей даёт менее 1,2 мм; полное расхождение к этому моменту уже превышает 14 см. На кадре 751 на прямой истории обе версии возвращают прогноз. На истории LaserScan поддержка прямого скана 0,3968 оказалась ниже порога 0,40, а преобразованный принят с поддержкой 0,5433. Первое различие статуса возникло спустя 726 кадров после первого сантиметрового расхождения.

## Подстановка одного кадра

В прямом обходе подменён ровно один скан; все последующие входы снова прямые. Вариант с кадром 1 сходится с контролем уже на следующей метке. Подстановка кадра 25 даёт 11,438 мм сразу, 9,429 мм через кадр и 1,050 м на последней метке. Подстановка кадра 72 даёт максимум 0,432 мм, в конце расхождение нулевое. Подстановка кадра 751 воспроизводит прямой контроль полностью. Один кадр может запустить накопление, а результат зависит от предшествующего состояния. Эти опыты не приписывают весь дрейф №139 единственному лучу.

## Воспроизведение

Сначала подготовьте прямую запись №108 и каталог сравнения №139. Скрипт проверяет точное воспроизведение обеих траекторий и записывает в новый JSON прогнозы, число точек дерева, статусы и соответствия. [Подготовка входов](intel-laserscan.md)

```powershell
$python = '.\.venv-mgts\Scripts\python.exe'
& $python -m tools.intel_scan_divergence out/intel139-data out/intel139-result out/intel143-result.json
```
