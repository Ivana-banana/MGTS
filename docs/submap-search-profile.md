# Время поиска старта по восьми участкам HEAP-1

Локальная траектория зависит от окна инспекции и выбранного способа сопоставления сканов. Все восемь карт получают одно и то же окно. В полевых сценариях №94 и №97 теперь достаточно одной проверки окна и одного построения локальной траектории. Для каждой карты по-прежнему выполняется собственный глобальный поиск. При отказе локального этапа каждая карта получает прежнюю причину отказа и пустой список опор.

| Первый кадр | Локальный этап, 8 раз, с | Локальный этап, 1 раз, с | Весь поиск до, с | Весь поиск после, с | Принято участков из 8 |
|---:|---:|---:|---:|---:|---:|
| 2560 | 4,45 | 0,58 | 50,96 | 46,44 | 1 |
| 2620 | 2,32 | 0,25 | 52,11 | 43,45 | 0 |
| 2680 | 2,11 | 0,25 | 48,50 | 42,41 | 0 |
| 2740 | 2,39 | 0,25 | 54,64 | 43,38 | 0 |

По четырём окнам локальный этап сократился с **11,28 до 1,33 с**, а измеренное полное время — с **206,21 до 175,68 с** (14,8%). Устранённые локальные расчёты объясняют около 10 с этой разницы, или 4,8% исходного времени. Остальную разницу нельзя приписать изменению алгоритма по одному прогону на общей машине. Основную часть времени по-прежнему занимает поиск опор на картах.

Для сравнения исходный процесс загружал код до правки. Время подготовки в нём измерялось до первого глобального поиска каждого участка. Во втором процессе отдельно измерялся единственный вызов подготовки каждого окна. Из общего времени в обоих случаях исключены чтение сканов и растров, построение карт и запись отчёта. Использованы восемь сохранённых сеток №94 и первые 51 из 60 сканов каждого окна, локальный метод `pairwise`. Эталонные траектории в измерении не читались.

Для всех 32 решений сериализованный JSON с позой или причиной отказа и полным содержимым диагностического словаря побайтово совпал до и после. Сверены конечные локальные позы и все 192 записи опор, включая оценки кандидатов и конкурентов. Решения и опоры совпали также с сохранёнными отчётами №94 и №97.

Для повтора на одной версии кода из корня MGTS в Windows PowerShell:

```powershell
& .\.venv-mgts\Scripts\python.exe -m tools.profile_submap_search out/heap1-long-80 out/heap1-heldout-37 out/issue94
```

Для каждого окна команда печатает номер кадра, два времени локального этапа и два полных времени в секундах. Сначала измеряется повторная подготовка, затем однократная. Расхождение в диагностике прерывает прогон.
