# Подтверждение уже принятого старта

Последующие сканы позволили **отклонить воспроизведённый ложный старт** с ошибкой 5,94 м и 179,43°. На шести контрольных стартах с полным обзором подтверждение сохранило все шесть правильных поз.

| Проверка | Односкановый метод принял | Подтверждено | Отклонено |
|---|---:|---:|---:|
| Правильные старты, полный обзор, seed 41 | 3 | 3 | 0 |
| Правильные старты, полный обзор, seed 73 | 3 | 3 | 0 |
| Ложный старт, дальность до 3 м, seed 73, скан 30 | 1 | 0 | 1 |

Экспериментальная функция `mgts_nav.start_confirmation.confirm_start` получает уже предложенную позу на метке первого скана. Второй глобальный поиск использует только более поздние облака и относительную кинематическую одометрию в окне до 3 секунд. Поиск выполняется на той же карте без подсказки от первой гипотезы. Обе оценки приводятся к метке первого последующего скана. Порог расхождения — 0,20 м и 6°. При согласии возвращается исходный кандидат. Расхождение, недостаток данных и неоднозначность последующего поиска приводят к отказу.

В целевом примере поиск по более поздним сканам обнаружил несколько сопоставимых положений на карте и отказал до сравнения порогов. Это остановило принятие ошибочной позы, но не восстановило истинный старт. Проверка требует последующих измерений и второго глобального поиска. Окно использует до 3 с данных и может задержать выдачу начальной позы; в офлайн-процессе можно буферизовать эти сканы.

## Как повторить

`python -m pytest -q -s tests/test_start_confirmation.py` заново строит карты коридора с клеткой 8 см для seed 41 и 73. Контрольные окна начинаются на сканах 0, 30 и 60 инспекции. Для целевого примера дальность ограничена на всех сканах окна. Истинная траектория участвует только при проверке ошибок. Третий тест исключает повторное использование первого скана и проверяет отказ при отсутствии данных в пределах окна. Результат исходного прогона — 3 пройденных теста.

На этих шести контролях потери правильных стартов составили 0 из 6. Одна геометрия, две реализации шума и один целевой ложный старт пока не дают оценки частоты ошибок на новых маршрутах. Общую геометрическую симметрию или ошибку карты могут унаследовать обе привязки.
